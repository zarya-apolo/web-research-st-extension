Web Research
off
Normalized web research tools for quick Tavily lookup and semantic/deep Exa research.
When this is set, Exa API URL must remain https://api.exa.ai. The test verifies the relay identity, its Exa route, and an actual Exa search.
Tool differences
web_research_quick: Tavily, fast wiki/synopsis/current lookup.
web_research_deep: Exa, semantic fandom/lore/powers/limitations research.
web_research_answer: Exa synthesized answer with citations.
web_research_auto: normalized router using the selected mode.
